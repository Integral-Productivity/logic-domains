The Flying Logic domain file is [self-organization.xlogicd](self-organization.xlogicd). It is copied from the source tree with `node scripts/extract-domain.mjs <tree.xlogic>`, or exported from Flying Logic with Entity > Export Selected Domain. To change a class, change it in Flying Logic, save the tree, and copy the file again. Do not edit or generate it: its class UUIDs keep existing trees linked.
